# IRON LOG — 筋トレ記録 PWA

iPhoneのホーム画面から起動できる、オフライン対応の筋トレ記録アプリです。

---

## 📁 ファイル構成

```
ironlog/
├── index.html        # メインHTML
├── app.js            # アプリロジック
├── obsidian.js       # Obsidian用Markdown書き出し
├── sync.js           # 複数端末同期（Supabase）
├── supabase.sql      # 同期用テーブル定義（SQL Editorに貼って実行する）
├── style.css         # スタイル
├── manifest.json     # PWA設定
├── sw.js             # Service Worker（オフライン対応）
├── icons/            # ← アイコン画像をここに入れる
│   ├── icon-32.png
│   ├── icon-72.png
│   ├── icon-96.png

│   ├── icon-152.png
```

## 🚀 使い方（ローカルで動かす）

### 方法 A：VSCode Live Server（推奨）
1. VSCodeで `ironlog` フォルダを開く
2. `index.html` を右クリック →「Open with Live Server」
3. iPhoneでPC側のIPアドレスにアクセス（例：`http://192.168.1.10:5500`）

### 方法 B：Python簡易サーバー
```bash
cd ironlog
python3 -m http.server 8000
```
→ `http://localhost:8000` にアクセス

### 方法 C：GitHub Pages（推奨・外出先でも使える）
1. GitHubに `ironlog` フォルダをリポジトリとしてpush
2. Settings → Pages → Source: main / root に設定
3. `https://ユーザー名.github.io/ironlog/` でアクセス可能

> ⚠️ PWA（Service Worker）は **https または localhost** でのみ動作します。
> GitHub Pages は自動でhttpsになるので最も簡単です。

## 📲 iPhoneのホーム画面に追加する方法

1. iPhoneのSafariでアプリのURLを開く
2. 画面下部の共有ボタン（□↑）をタップ
3.「ホーム画面に追加」を選択
4. 名前を確認して「追加」

これで**ネイティブアプリのように**使えます（オフラインでも動作）。

## ✨ 機能一覧

### 🏋️ トレーニング画面
- 種目ごとにカードで管理
- **セット記録**：ボタンをタップするたびにカウントアップ
  - 各セットの記録時刻を表示
  - 「↩ 取消」で最後のセットを削除（誤操作対策）
- **レストタイマー**（補助機能・セット記録とは独立）
  - カウントダウン：設定秒数から0へ（60/90/120/180秒プリセット＋カスタム）
  - ストップウォッチ：上限なしで増加
- 種目カードのドラッグ＆ドロップで並び替え

### ✏️ 種目編集
- 種目の追加・削除・名前変更・重量変更

### 💾 ログ保存
- その日の種目・重量・セット数とそのセッションの総重量を記録
- **1日に何回でも保存できる**（朝／夜のセッションが別々の記録として並ぶ）
- 日付をまたいで記録していると警告が出る。「始めた日」の記録として保存される

### 📅 ログ画面
- 日付ごとにまとめて表示（筋トレ＋有酸素）
- 1件ずつ **日付・時刻の変更**と**削除**ができる

### 📊 統計画面
- **累計扱った総重量**（ログから毎回計算するので、編集・削除しても必ず合う）
- 記録日数・1日平均重量
- 直近8セッションの総重量グラフ

### 🗒 Obsidian 書き出し
統計画面から3つの形式で書き出せます。iPhone では共有シートが開くので、
Obsidian の保管庫（Vault）に保存してください。

| 形式 | 中身 |
|---|---|
| 一式（ZIP） | `筋トレ.md`（サマリー）＋ `日別/2026-08-05.md` ＋ `種目別/ベンチプレス.md`。`[[リンク]]` で相互に繋がる |
| 日別だけ（ZIP） | `日別/YYYY-MM-DD.md` のみ。Obsidian のデイリーノートと並べたいとき |
| 1ファイル（.md） | 全部を1枚にまとめたもの |

### ☁️ 複数端末で同期
統計画面からメールアドレスとパスワードでログインすると、複数の端末で記録を共有できます。
ログインしなければ今までどおり、その端末だけに保存されます。

**初回だけ必要な準備**
1. Supabase のダッシュボード → SQL Editor に `supabase.sql` を貼って実行する
   （わんにゃんメモリー・達人への道と同じプロジェクトに相乗りしています）
2. アプリの統計画面 →「ログイン / 新規登録」→ 新規登録
3. 確認メールのリンクを開いてから、改めてログイン
4. 2台目以降は同じメールアドレスでログインするだけ

同期は、記録を保存したとき・アプリを開いたとき・オンラインに復帰したときに自動で走ります。
オフラインでも通常どおり使えて、繋がったときにまとめて送られます。

---

## 🔒 データについて
データはブラウザの `localStorage` に保存されます。
同期にログインしていない限り、サーバーには一切送信されません。
アプリをアンインストール（Safariのデータを消去）するとデータも消えるので、
**同期を使うか、定期的にエクスポート**しておくことをおすすめします。
